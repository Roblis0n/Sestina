# @sestina/core

Authoritative local application entry point for the research revision lifecycle.
Consumers call use cases and queries; repositories, SQLite handles, migrations,
and transaction boundaries remain private to this package.

The Core covers project setup, Brief/Artifact/Revision preparation, Decision
and Issue transitions, deterministic Review execution, explicit Episode user
disposition and scoped waiver, immutable Snapshot integrity, standalone
Markdown/JSON reports, and minimized Capsule projections. Model proposals and
system findings remain structurally separate from user authority.
