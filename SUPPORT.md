# Support / 支持

Sestina 0.2.0 is a public preview. Before reporting a problem, verify that you
are using one supported artifact (Windows x64, macOS arm64, or Ubuntu x64),
Node.js 24.x, and a matching SHA-256 from the same `v0.2.0` Release.

Sestina 0.2.0 是公开预览。反馈前请先确认使用 Windows x64、macOS arm64 或
Ubuntu x64 的对应制品、Node.js 24.x，并已用同一 `v0.2.0` Release 的 SHA-256
完成校验。

For ordinary bugs, use the repository's structured bug form. Use synthetic,
minimal data only. Never post research content, a real `.sestina` database,
Research Brief, Provider response, secret, token, API key, project path,
personal path, device identifier, raw logs, stdout/stderr, or screenshots that
contain private material.

普通问题请使用仓库中的结构化 Bug 表单，并只用合成、最小化数据。禁止发布
研究内容、真实 `.sestina` 数据库、Research Brief、Provider 响应、密钥、token、
API key、项目或个人路径、设备标识、原始日志、stdout/stderr，或含隐私材料的截图。

For a suspected vulnerability, do not open a public issue. Follow
[SECURITY.md](SECURITY.md) and use a private GitHub Security Advisory.

疑似漏洞不得创建公开 Issue，请按 [SECURITY.md](SECURITY.md) 使用 GitHub 私密
Security Advisory。

This public preview has no service-level guarantee. Reports may establish a
reproducible defect; they do not by themselves establish research validity,
Provider quality, adoption, or market value.

本公开预览不提供服务等级保证。问题报告可以证明可复现缺陷，但不会自动证明
研究有效性、Provider 质量、外部采用或市场价值。
