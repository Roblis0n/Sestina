# Public-preview participation consent / 公开预览参与同意

Consent：`2026-08-30`
Pilot Kit：`2.0.0`

Participation is voluntary. You may refuse any field, stop at any point, or ask
for deletion of your exact local Pilot session. You decide whether an anonymous
structured export is created and whether it is shared. Stopping or reporting a
failure has no penalty and will not be relabelled as success.

参加完全自愿。你可以拒绝任何字段、随时停止，或要求删除精确的本地 Pilot
session。是否创建匿名结构化 export、是否分享，均由你决定。退出或报告失败
不会带来惩罚，也不会被改写成成功。

Sestina and the Pilot runner operate locally. They do not automatically scan
your project, research material, `.sestina` state, conversations, clipboard,
command history, or network. They do not send telemetry or automatically upload
evidence.

Sestina 与 Pilot runner 在本机运行，不自动扫描项目、研究材料、`.sestina` 状态、
对话、剪贴板、命令历史或网络，也不发送遥测或自动上传证据。

The optional shareable export contains only opaque IDs, fixed categories,
booleans, counts, minutes, release platform/source/hash, bounded journey and
failure outcomes, burden scores, repeat-use facts, and an integrity hash. It
contains no free text, name, contact, institution, research content, title,
Brief/Decision/Issue/Finding text, project path, personal path, device ID,
secret, token, API key, environment value, Provider response, raw error, log,
stdout/stderr, screenshot, or conversation.

可选 export 只含 opaque ID、固定分类、布尔值、计数、分钟数、发布平台/来源/hash、
受限旅程与失败结果、负担评分、重复使用事实和完整性 hash。它不含自由文本、
姓名、联系方式、机构、研究内容或标题、Brief/Decision/Issue/Finding 正文、项目
或个人路径、设备 ID、密钥/token/API key、环境值、Provider 响应、原始错误、
日志、stdout/stderr、截图或对话。

This study does not promise research improvement and does not claim ethics or
IRB approval. If approval is required where the study is organized, collection
must wait. / 本研究不承诺改善研究，也不声称已有伦理或 IRB 批准；如当地要求，
批准前不得收集。

A session may be created only after you have read this page, voluntarily agree,
and explicitly acknowledge consent version `2026-08-30`.

只有在你阅读本说明、自愿同意并明确确认 consent version `2026-08-30` 后，才可
创建 session。
