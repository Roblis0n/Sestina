# Public-preview behavior results / 公开预览行为结果

Release: `0.2.0` / `public_preview`
Protocol/consent: `2026-08-30`
Pilot Kit: `2.0.0`

## Evidence boundary / 证据边界

- Eligible independent external participants: `0`
- Eligible external sessions: `0`
- Excluded owner/internal/synthetic sessions: `0`
- Valid session-1/session-2 participant pairs: `0`
- Required behavior field groups complete: `unproven`
- Sample status: `insufficient_external_sample`
- Second-use status: `second_use_unproven`
- Next-stage evidence gate: `not_eligible`

## Required behavior groups / 必填行为组

Report completeness and missing counts separately for:

1. platform and release binding;
2. download/checksum/extraction/first launch/time-to-room/failure point;
3. project/Brief/review/Manifest/disposition/Receipt journey;
4. relaunch and recovery;
5. local-web lifecycle and friction;
6. burden, failure, negative, exit, and willingness outcomes;
7. repeated-correction impact and session-2 fact;
8. Desktop need and bounded supporting evidence.

## Denominator report / 分母报告

For every rate record numerator, denominator, missing count, and opaque evidence
IDs. Include all eligible failed, abandoned, negative, blocking, and unwilling
outcomes. Do not publish free text, research content, identities, paths, device
identifiers, secrets, raw errors, logs, or screenshots.

每个比例均记录 numerator、denominator、missing 与 opaque evidence ID；保留全部
合格失败、放弃、否定、阻塞和不愿再次使用结果。禁止发布自由文本、研究内容、
身份、路径、设备标识、密钥、原始错误、日志或截图。

## Decision discipline / 决策纪律

Aggregation does not output Go/No-Go. Fewer than five eligible independent
external researchers, no valid pair, or any incomplete required field group
means the next-stage evidence gate must remain waiting. Even when eligible, the
user must inspect behavior evidence before any further product decision.
Expansion is never automatic.

汇总不输出 Go/No-Go。少于 5 名合格独立外部研究者、无有效配对或任一必填字段组
不完整，下一阶段证据门必须继续等待；即使达到门槛，也要由用户审阅真实行为
证据，绝不自动扩张产品范围。
