# Bounded exit interview / 有界退出访谈

Use selections only. Do not collect free text in the shareable export. A
participant may decline and stop.

只使用固定选项；可分享 export 不收集自由文本。参与者可拒答并随时停止。

1. Did Sestina reduce repeated correction? `reduced` / `unchanged` /
   `increased` / `uncertain`.
2. Would you use it again on a real task? `yes` / `no` / `uncertain`.
3. Preferred entry: Research Room / Research Room with MCP / recovery CLI /
   multiple / none.
4. Was a native Desktop form needed? `none` / `helpful` / `required` /
   `uncertain`.
5. What evidence supports the Desktop answer? none / self-report only /
   observed workaround / blocked without Desktop / uncertain.
6. Was a UI needed? `yes` / `no` / `uncertain`.
7. Was a synthetic-case discussion requested? `yes` / `no` / `undecided`.
8. Rate maintenance burden 1–5 for Brief, Decision, Issue, Manifest, Recovery.
9. Did any failure or negative feedback occur? record each boolean honestly.

If the participant exits, record only one bounded point: download, checksum,
extraction, first launch, project, Brief, review, Manifest, disposition,
Receipt, recovery, relaunch, second task, local web lifecycle, or other.

如参与者退出，只记录一个固定退出点。禁止为了“完整”而补写未观察事实，禁止因
结果不利而删除记录。
